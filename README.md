# 🛡️ Cloud IAM & Security Engineering Lab

Hands-on enterprise security and Identity & Access Management (IAM) laboratories demonstrating least-privilege policy engineering, cross-cloud federation, and automated identity governance workflows across AWS and Microsoft Azure.

---

## 🎯 Repository Overview
This repository serves as a portfolio of production-aligned security implementations. Each lab is structured to solve common enterprise identity challenges—ranging from cloud-native permission boundaries to automated lifecycle provisioning and multi-region network hardening.

---

## 📂 Laboratory Architecture & Structure

| Module | Focus Area | Key Technologies & Concepts |
| :--- | :--- | :--- |
| **`project-1-aws-iam`** | AWS Least-Privilege IAM | Custom IAM policies, permission boundaries, resource-based policies, and automated validation scripts. |
| **`project-2-azure-entra-id`** | Azure Entra ID Governance | Conditional Access policies, role-based access control (RBAC), and group-based licensing management. |
| **`project-3-sailpoint-entra-iga`** | Identity Governance & Administration | SailPoint IGA integration with Microsoft Entra ID, automated access requests, and certification campaigns. |
| **`project-4-enterprise-iam-lifecycle`** | Provisioning & Automation | SCIM provisioning, identity lifecycle workflows, and parameterized PowerShell/Python scripts. |
| **`project-encryption-kms-secrets`** | Cryptographic Controls | AWS KMS key management, customer-managed keys (CMKs), secret rotation, and secure parameter storage. |
| **`project-storage-s3-security`** | Cloud Storage Hardening | S3 bucket policies, public access blocking, object encryption enforcement, and CloudTrail auditing. |
| **`project-vpc-network-hardening`** | Network Segmentation | Custom VPCs, public/private subnets, security groups, network ACLs, and flow log analysis. |

---

## ⚙️ Core Engineering Competencies
* **Identity & Access Management:** RBAC/ABAC models, enterprise directory federation (SAML/SCIM), and least-privilege policy design.
* **Governance & Automation:** Identity lifecycle management, access reviews, and script-driven auditing workflows using PowerShell and Python.
* **Multi-Cloud Security:** Infrastructure hardening, logging configuration, and perimeter defense across AWS and Azure environments.
