# Project 4: Enterprise IAM Identity Lifecycle & Automated Provisioning

## Objective
Design and deploy a hybrid identity lifecycle management lab utilizing Windows Server Active Directory, Microsoft Entra ID, and automated PowerShell scripts to handle bulk user onboarding, modification, and deprovisioning in alignment with enterprise security and SOX compliance standards.

## Architecture & Components
* **Identity Store:** Windows Server Active Directory (Domain Controller)
* **Cloud Directory:** Microsoft Entra ID (Azure AD) via Entra Connect Sync
* **Automation Engine:** PowerShell (Lifecycle Provisioning & Offboarding)
* **Access Governance:** Role-Based Access Control (RBAC) & Access Review Documentation

## Implementation Roadmap
* [ ] Phase 1: Windows Server Active Directory & OU Structure Setup
* [ ] Phase 2: Hybrid Cloud Sync with Microsoft Entra ID
* [ ] Phase 3: Automated Onboarding & Offboarding PowerShell Scripts
* [ ] Phase 4: Access Certification & Audit Reporting Documentation
