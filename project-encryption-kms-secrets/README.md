# AWS KMS & Secrets Management Lab

## Project Overview
Configuring Customer Managed Keys (CMKs) in AWS Key Management Service (KMS) and managing sensitive credentials securely using AWS Secrets Manager to protect data at rest.

---

## Architecture & Security Controls Implemented
* **Customer Managed Key (CMK):** Created a dedicated KMS key for encryption control and auditing.
* **Key Policies:** Defined least-privilege permissions on who can use and administer the encryption key.
* **Secrets Management:** Stored and retrieved simulated database credentials securely using AWS Secrets Manager.
